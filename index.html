C++ USTRUCT Definitions unreal_structs.h

Drop into your Unreal C++ Source folder. Fully blueprint-accessible USTRUCT definitions.

Download unreal_structs.h
How to use in Unreal Engine 5:
  1. Copy unreal_structs.h into your Unreal project's Source directory and compile.
  2. In Unreal Content Browser, right-click > Miscellaneous > Data Table, select FRCEventTableRow (for events) or FRCDialogueTableRow (for dialogues).
  3. Right-click the newly created DataTable > Reimport With New File > select unreal-events.json or unreal-dialogues.json.
  4. All narrative event nodes, action options, crew requirements, specialization rewards, and dialogues are native Unreal gameplay assets!
