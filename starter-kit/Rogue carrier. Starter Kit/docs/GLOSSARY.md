# Glossary

| term | meaning |
|---|---|
| run | one game from a fresh map to a win or a loss (roguelite) |
| XP, experience, Knowledge | what wins a run; the game data calls it Knowledge; earned from quests, events and programs |
| variation | the game data's word for a run |
| Behemoth | the player's ship; buildings stand on its deck |
| entropy | run-wide level 0-10; raised by extraction, buildings, engine and waste; drives dangerous events |
| blueprint | an item needed to research buildings in the R&D Lab |
| R&D Lab | ship system that offers buildings to unlock during a run |
| program | a tier-5 win item: Positron Cell, Satellite, Transhuman Form (crafted) or the Antimatter Core Unit (a building) |
| tier (T0-T5) | depth of an item in the crafting tree: T0 raws, T1-T4 crafted, T5 programs |
| raw | a tier-0 resource gathered from the world |
| rarity | Common, Uncommon, Rare, Exotic, Unique (raws) |
| K-IV | the sea organics (Plankton, Algae, Krill, Aminoacids), gathered only from seaweed |
| recipe | the slots an item is crafted from |
| slot | one position in a recipe or a build cost; filled with ONE of its options |
| option | one alternative ingredient of a slot |
| grade (g1-g3) | recipe quality of an item in a given building (low / mid / high efficiency); g3 = fewest inputs, fastest; g2 x1.4 inputs, g1 x1.8 |
| host | a building that crafts an item (its recipe "line") |
| line | one recipe a production building can run; at most 4 per building |
| build cost | the slots a building is built from |
| start kit | items the player has at the start (`UE_StartResources`); the Tech Assembly Matrix pays for the first energy buildings |
| component | an item used only as an ingredient or building material |
| consumable | an item used up in play (food, medicine, ammo, power cell, capsule, pulse, rechargeable device, implant) |
| unit | a vehicle built in the Hangar (Worker Drone, Freighter, Recon Craft, Deep-Sea Trawler) |
| capsule | a consumable launched by the Mass Driver (Basic Extractor, D.A.R.T., Underground Deposit Extractor, Surveying Probe) |
| branch | grouping of raws and items (metal, electronics, chemistry, energy, organics) from the outdated v14.3 draft; not in the game |
| function (tag) | label of the job a slot does, from the outdated v14.3 draft; not in the game |
| race, species | alien peoples met on quests; crew species: Human, Nasobi, Crabari, Knidaria, Aetherid, Mistralid; also Luminid and Auri in quests and goods |
| race building | a building of a race; not in every run; hosts bonus recipes (race foods) |
| race goods | 18 trade goods (3 each for Nasobi, Aetheridis, Crabri, Luminid, Auri, Knidaria); cannot be crafted, only bought |
| biome | Polar, Rocky, Volcanic, Temperate, Tropical, Shallow, Desert (the team sheet adds Deep Sea); decides which raws are plentiful |
| tile | map cell, 2.5 km square; the map is 100 x 100 tiles |
| island | one land tile; a big island is a 2x2 block |
| island group | islands that touch by an edge; one group lies in one biome |
| floating island | a levitating object over water; the ship sails under it |
| seaweed | a floating object under the surface; seen only close up; the source of K-IV organics |
| reef | passable water that damages the ship per distance sailed over it |
| map index / seeds | which generated world; each generator layer has 256 seeds of its own |
| prototype grid | the crafting grid in the current game build; the one to use |
| grid v14.3 | an OUTDATED DRAFT of the designer's rework; does not match the game or the current design; direction of change only, never a data source |
| team sheet | the team's workbook *Economy v0.2*; its `UE_*` tables are exported to Unreal |
